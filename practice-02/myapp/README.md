# Практическая работа #2: Модульное веб-приложение на Go, реализованное по стандартам структуры проектов.

## Структура проекта
* `cmd/myapp/main.go` — точка входа в приложение.
* `internal/app/app.go` — инициализация сервера, роутер и middleware для отслеживания `X-Request-Id`.
* `internal/app/handlers/ping.go` — изолированный обработчик маршрута `/ping`.
* `utils/logger.go` — утилита для логирования входящих HTTP-запросов и системных сообщений.
* `utils/httpjson.go` — хелперы для отправки JSON-ответов и стандартизированных ошибок (`WriteErr`).
* `go.mod` — файл описания модуля Go.

## Запуск проекта
Для запуска сервера выполните в терминале:
```powershell
go run ./cmd/myapp
