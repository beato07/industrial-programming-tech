# Практическая работа #1: Разработка минимального HTTP-сервиса на Go

## Цель работы
1. Развернуть рабочее окружение Go на Windows.
2. Создать минимальный HTTP-сервис с использованием стандартной библиотеки `net/http`.
3. Подключить и использовать внешнюю зависимость (генерация UUID).
4. Собрать исполняемый файл и проверить работоспособность приложения.

---

## Описание проекта
Проект представляет собой простой HTTP-сервер на Go, который реализует несколько эндпоинтов:
* `/hello` - возвращает текстовое приветствие.
* `/user` - возвращает JSON-ответ с уникальным идентификатором (`UUID`), сгенерированным с помощью внешней библиотеки.
* `/health` - возвращает статус сервера и текущее время в формате RFC3339.

Например:
```bash
curl.exe -i http://localhost:8080/hello
```

## Примечания по конфигурации
* **Порт по умолчанию:** Сервер ожидает входящие подключения на порту `8080`.
* **Изменение порта:** Вы можете переопределить порт с помощью переменной окружения `APP_PORT`.

## Сборка и запуск
Проект можно запустить двумя способами в зависимости от вашей цели:

### Способ 1: Быстрый запуск в режиме разработки (`go run`)

```bash
# Перейдите в папку с проектом (если вы еще не там)
cd practice-01/helloapi
```

```bash
# Запустите сервер
go run ./cmd/server
```

### Способ 2: Сборка исполняемого файла (`go build`)

```bash
# Соберите проект (файл сохраняется в корне helloapi)
go build -o helloapi.exe ./cmd/server
```

```bash
#Запустите полученный исполняемый файл
./helloapi.exe
```
